# PatitasIN · página web

Página informativa de PatitasIN, la app del barrio para encontrar mascotas perdidas en Santa Cruz de la Sierra:
qué hacemos, funciones, seguridad, metas, aliados y el enlace a Google Play.

Es una sola página estática (`index.html`, sin scripts). Las imágenes están en `img/`. Las capturas son de la
app real.

La app está en otro repositorio: [Azzaccell/PatitasIN](https://github.com/Azzaccell/PatitasIN).

**En vivo:** https://azzaccell.github.io/PatitasIN-Web/

## Publicar
GitHub → Settings → Pages → *Deploy from a branch* → `main` / `(root)`.

## Pendiente
- Cuando la app esté en Google Play: cambiar el botón «Muy pronto en Google Play» por el sello oficial y el
  enlace `https://play.google.com/store/apps/details?id=com.patitas.japon`.
- Si se compra un dominio: agregarlo en Settings → Pages y cambiar `og:url` y `og:image` en `index.html`.
